# Frontend (TypeScript)

This is the frontend for the the final exam application.

## Tech Stack

- [TypeScript](https://www.typescriptlang.org/)
- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)

### Prerequisites

- Node.js ≥ 18

- npm or yarn

- Expo CLI (for React Native apps):

- Python 3.13 or later
- MongoDB running (local or remote)
- pip package manager
  npm install -g expo-cli

## Setup

1. Clone the repo:<br> `git clone https://github.com/Magnuskyh/Barcode_scanner_fe.git`

2. Navigate to the project folder:<br>`cd \your\path\to\barcode_scanner_fe`

3. Open CMD in the project folder.

4. npm install

5. npm start

6. expo start
